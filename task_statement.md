# SWE-Prometheus Public Task Statement

You are given a fixed snapshot of a real repository. Improve its engineering governance without removing or breaking existing runnable behavior. Inspect the repository and prioritize risks across these six dimensions:

1. Tests and CI
2. Code quality gates
3. Documentation and collaboration
4. Structure and maintainability
5. Reproducible environment
6. Dependency and interface health

The agent must make a defensible retrofit and verify that existing behavior remains preserved. There is no issue list, defect list, oracle patch, target score, or reference answer.
